## 13. Supplier Confidentiality

**IMPORTANT:** Buyer-facing documents NEVER show supplier information.

- Buyer quotes/orders/invoices show items WITHOUT supplier names
- Supplier column in admin views is for INTERNAL margin analysis only
- PDF exports to buyers exclude all supplier references
- This protects supplier relationships and business model
